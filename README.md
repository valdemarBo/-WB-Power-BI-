## Описание

Power BI дашборд для анализа продаж на маркетплейсе Wildberries на основе стандартного отчета "Реализация товаров".

## Файлы

| Файл | Описание |
|------|----------|
| `Отчёт о продажах по реализации WB.pbix` | Дашборд Power BI |
| `Отчет о продажах по реализации.xlsx` | Исходные данные (выгрузка WB) |

## Основные метрики

- Выручка (общая и чистая)
- Комиссии и удержания
- Рентабельность
- Возвраты
- Динамика продаж по дням

## Как использовать

1. Скачайте оба файла в одну папку
2. Откройте `.pbix` в Power BI Desktop
3. При необходимости обновите путь к Excel-файлу

## Особенности

- Календарь построен на `rr_dt` (дата расчетной реализации)
- Комиссии с минусом = удержания, с плюсом = возвраты комиссий

## Требования

- Power BI Desktop (бесплатно)
- Windows 10/11
